Alison adds free in-browser Python coding labs

By the CourseGauge editors · Published October 16, 2026

Free course platform Alison announced Interactive Coding Labs on October 15, 2026, starting with Python. Instead of only watching video lessons, learners type and run Python code in an editor that sits next to the lesson instructions, then see straight away whether it works. Alison says there is nothing to install: the coding environment runs in the browser.

What's available

According to Alison's announcement, the collection is one foundation course followed by six advanced specialisations. Five courses are live now: the Complete Python Bootcamp, which Alison pitches as taking learners from beginner to upper-intermediate, and Advanced Python courses for data analysis, machine learning, web development, and automation and scripting. The other two specialisations are due in November 2026.

Like the rest of Alison's catalogue, the courses are free to study and complete. A certificate or diploma is an optional purchase after you pass.

Why it matters if you're learning to code

Write-and-run practice inside the lesson has been one of the main reasons people pay for platforms such as Codecademy and DataCamp, and it is the format many beginners find sticks better than video alone. Codecademy already has a free Basic tier, but its paid Plus and Pro plans start at $14.99 a month billed annually (US list price, checked October 15, 2026). A free hands-on Python option from Alison gives beginners on a zero budget another way to practise before deciding whether a paid plan is worth it.

Two caveats. First, we have not yet worked through the new labs ourselves, so treat this as news rather than a review. Second, Alison's certificates are its own CPD-accredited credentials, not university certificates; if you need a credential employers widely recognise, compare the options in our certificates guide.
