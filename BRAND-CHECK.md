# Brand name check, October 15, 2026

## "Studyvane" (original working name): dropped
- studyvane.com is already registered (Verisign RDAP returned 200).
- A web search turned up an existing "StudyVane" AP Physics and Computer Science practice platform, and a similar-sounding education brand, Study Van (studyvan.com, Study Van LLC).
- Both are in the education space, so the conflict risk was high.

## Other names checked (.com status from Verisign RDAP)
- **Already registered:** courseverdict, lessonledger, tuitionscope, classgauge, skillscout, learnlens, courseply, veralearn, cairnlearn.
- **Not registered:** coursetrue, coursecairn, coursegauge.
- **CourseCairn rejected:** "Cairn" is already used by a study tool (cairnstudy.com) and by Cairn University's online learning.

## Chosen name: CourseGauge
- **Domain:** coursegauge.com was not registered when checked. We did not buy it.
- **Web search:** no exact "CourseGauge" or "Course Gauge" brand found.
- **Trademarks:** the nearest marks are COURSE REPORT (Class 41, a different phrase) and GAUGE (knitting goods in Class 26, and an abandoned software filing). Neither is confusingly similar for course reviews.
- **USPTO:** the official search at tmsearch.uspto.gov needs an interactive browser, so it could not be run from the box. Joshua should search "coursegauge" and "course gauge" there before filing or launching.
- **GitHub:** github.com/coursegauge returned 404, so the username was not taken.
- **Logo:** an original SVG gauge drawn for this site.
